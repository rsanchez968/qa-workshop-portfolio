# Charters de Testing Exploratorio

## Charter 1 (API - Swagger)

* **Título:** Exploración de endpoints de gestión de mascotas y actualización de estados.
* **Misión:** Explorar las operaciones `POST /pet` y `PUT /pet` de Swagger utilizando datos válidos, límite e inválidos para descubrir inconsistencias en la validación de esquemas y códigos de respuesta HTTP.
* **Área principal explorada:** API REST Swagger (https://petstore.swagger.io).

## Charter 2 (Web UI - JPetStore)

* **Título:** Exploración del flujo de navegación de catálogo y carrito de compras.
* **Misión:** Explorar el catálogo web de OctoPerf, búsqueda de productos y adición al carrito con múltiples categorías para evaluar la persistencia de sesión y manejo de errores de interfaz.
* **Área principal explorada:** Aplicación Web (https://petstore.octoperf.com/actions/Catalog.action).
